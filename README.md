# 此刻 · 飞书诗词书摘推送

2026 年 8 月下旬到 11 月中旬，我用一台腾讯云轻量服务器（1.9G 内存）跑了几条定时任务，每天往自己的飞书群推诗词和书摘。这个仓库是它的存档与复盘。

推的内容不多，但中间踩的坑值得留档：**用大模型"生成"名言，伪托率高到不可用**。

---

## 推过什么

| 任务 | 时间 | 内容 | 现在 |
|---|---|---|---|
| **此刻** | 每天 3～7 条（随语料余量调整） | 一句诗词或书摘 + AI 写的两三句引读 | 在跑 |
| **每日诗词** | 每天 07:30 | 一首古诗词 + AI 白话赏析，周末换成文青句子 | 已停 |
| **今日掌故** | 每天 07:00 | 一个典故的真实史事 + 中外历史上的今天 | 在跑 |
| 每日概念寓言 | 每天 09:04 | 一个研究生级概念编成寓言 | 已停 |
| 每日英语 / 学科趣闻 | 每天 09:00 | 口语俚语 5 条 / 跨学科小故事 | 已停 |

「此刻」是唯一一条真正跑久的线。它的机制是**顺序轮播 + 最近去重**：语料分成多批 JSON 文件，指针 `{batch, index}` 逐个往前推，推送过的句子写进 `history`，每次取句跳过最近 1000 条内出现过的文本。语料见底时会退化成 6 条兜底名句循环——这种退化很难自己发现，所以后来加了余量告警。

## 存档到了什么程度

先说清楚：**不是全都有**。

| 内容 | 存档 | 说明 |
|---|---|---|
| 「此刻」已推送 | ✅ 718 条 | 原文 + 作者 + 出处，**但没有日期字段**，日志里也没打时间戳，推送时间无法还原 |
| 诗句语料库 | ✅ 663 条 / 7 批 | 344 位作者，含尚未推送的存货 |
| 每日诗词 | ❌ 无 | 当时没有落盘设计，正文随推随丢。现在脚本里也没有 history 机制 |
| 每日概念寓言 | ⚠️ 仅目录 | `concept_history.json` 只有概念名、时间、字数，**正文没存** |
| 每日英语 / 学科趣闻 | ⚠️ 仅目录 | `learn_history.json` 只有主题名 + 日期，正文没存 |
| 今日掌故 | ⚠️ 仅目录 | `history_state.json` 只有 19 个已用过的典故名，正文没存 |

也就是说，这个仓库能给出的最完整的东西是「此刻」的 718 条，加上 663 条语料。其余几项只剩个目录，正文找不回来了。

## 数据可信度分两档

718 条已推送里，**559 条**能对上语料库，**159 条**对不上。后者来自 8—9 月早期的 AI 生成批次，作者和出处都没验证过。

- [`docs/已推送-可溯源.md`](docs/已推送-可溯源.md) — 559 条，语料取自古文岛名句库
- [`docs/已推送-来源不可考.md`](docs/已推送-来源不可考.md) — 159 条，**引用前必须自己核实**

`pushed/unverified.json` 里那些熟面孔最典型：张爱玲、王小波、村上春树、尼采、里尔克。这类"名人金句"在中文互联网上流传的版本本身就层层转手，模型照着学，自然学会了一堆张冠李戴。

## 语料的来源

全部来自 [古文岛](https://www.gushiwen.cn/mingjus/default.aspx)（gushiwen.cn）名句库检索。抓取方式是解析列表页和作品页的 HTML，每条都带作者和原篇名。

第 7 批 239 条额外做过一次**逐条回查**：打开每句对应的作品原文页，把名句在正文里做去掉标点的逐字比对。首轮 231/239 通过，剩下 8 条是对不上，逐条打开原文发现都不是编的，而是异文用字或作者别称：

| 名句页写的 | 作品原文 |
|---|---|
| 流到瓜州古渡头 | 流到瓜**洲**古渡头 |
| 今日花开已一年 | 今日花开**又**一年（注"一作：已一年"） |
| 断桥人不度 | 断桥人不**渡**（注"一作：度"） |
| 著意随堤柳 | 著意**隋**堤柳 |
| 睡起秋色无觅处，满阶梧桐月明中 | 睡起秋**声**无觅处，满阶**梧叶**月明中 |
| 洪升 | 洪**昇** |
| 惠洪 | 释德洪（法名） |
| 潘安 | 潘岳（潘安是别称） |

一律以作品页原文为准订正，改完复验 239/239 全部命中。

## 一条教训

最初的做法是让模型直接"写"一批名言卡，150 条里 **109 条作者是编的**——不存在的篇目、把佛经名当人名、把朱熹的句子挂到唐庚名下。剩下 41 条里，27 条读起来像真的但其实查不到。

换成"给一份可信作者白名单，只准从里面挑"也没用，反而更糟：白名单把聂鲁达、马查多、洛尔迦、阿特伍德、策兰、特朗斯特罗默、米斯特拉尔、毕肖普全判成可疑作者，连续 10 轮只产出 1 条新内容，扔掉了 162 条。

**唯一可行的路是检索，不是生成。** 抓一个有人编辑、有作品原文可回查的语料库，然后机械地去重。这也解释了为什么最后的 239 条里一条外国作家都没有——中文古典是唯一能做到"句句可追溯"的区间。
